# KG_construct 说明

## 作用

这个目录负责把病例文本抽取成知识图谱。

流程：

1. 从 `input/` 读取病例文本
2. 用本地大模型抽取实体和关系
3. 写入 Neo4j
4. 生成 `output/` 下的抽取结果

## 主要入口

- `main.py`：主入口
- `main2.0.py`：兼容入口，调用主流程
- `get_labels.py`：抽取/更新标签

## 重要文件

- `llm_call.py`：模型加载与推理
- `neo4j_build.py`：Neo4j 连接和建图
- `read_and_write.py`：输入输出读写
- `process_output.py`：解析模型输出
- `prompt/prompt0.py`：提示词模板

## 配置

以下内容不再写死在源码里：

- 模型路径：使用 `MODEL_PATH`
- GPU：使用 `CUDA_VISIBLE_DEVICES` / `MODEL_DEVICE`
- Neo4j：使用 `NEO4J_URI` / `NEO4J_USER` / `NEO4J_PASSWORD`

## 运行前提

- 已准备好本地模型
- Neo4j 已启动
- `input/` 中有待处理的文本
